Нейросеть V00001

16.04.25 - 

Создал все основные классы для нейросети. Отлично справляется с задачами по типу логических операций и проверки на деления. С более сложными задачи и более большой архитектурой (100+ нейронов) уже проблемы. На данный момент имеется неплохая оптимизация, но для финальной цели потребуется ещё больше. Обучения практически не происходит на данном этапе - нейросеть быстро скатывается в локальный экстремум. Нужно подумать над адаптивной скоростью обучения, например, оптимизатор. Так нужно будет избежать "Плато" и, хоть и медленно, но идти вперёд. 

Моё текущее устройство вполне поддерживает текущий объём вычислений. Оно и не удивительно, использование нескольких ядер позволило задействовать 100% мощностей процессора. Буквально. И даже при такой работе обучение нейросети архитектурой 16, 64, 32, 16, 4 (132 нейрона) занимает 20-30 минут времени с практически никаким результатом. Плохо, но это поправимо. Вероятно, финальная или околофинальная нейросеть будет иметь 5000+ нейронов, что будет занимать очень, очень много времени на обучение. Нужно подумать над делегированием вычислений другому устройству.

К счастью, я создал методы для сохранения и загрузки нейросети. Нейросеть можно обучать в несколько этапов, сохраняя промежуточные значения в файл. Для файла был выбран уникальный тип .nn. Такой файл содержит все данные о нейросети и позволяет продолжить обучения с места сохранения. Удобно. Можно ещё передавать такой файл, например обучить на одном устройстве и отправить на другое.
